# Landing Page

---

## Prerequisites

* **Node.js**: `v18.17.0` or higher (v20.x recommended)
* **Package Manager**: `npm` (comes with Node.js), `pnpm`, or `yarn`
---

## Environment Setup

1. **Clone the Repository:**
   ```bash
   git clone git@github.com:neet-007/awssbg.git
   cd awssbg
   ```

2. **Install Dependencies:**
   ```bash
   npm install
   ```
## Database Setup

1. **Push Database Schema:**
   ```bash
   npm run db:push
   ```

2. **Seed Mock Data:**
   ```bash
   npm run db:seed
   ```

## Running Dev Server

```bash
npm run dev
```
